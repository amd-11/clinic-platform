## 1. Что это за проект

Портфолио-проект **Aurora Dental** — сайт стоматологической клиники с онлайн-записью,
админ-панелью и уведомлениями в Telegram. Клиника, врачи и отзывы **вымышленные**:
проект задуман как шаблон, который можно перепродавать реальным клиникам
(клиникам, салонам красоты, барбершопам).

Автор: Aren Mkrtchyan (GitHub `amd-11`), junior-разработчик из Еревана.
Цель — портфолио для фриланса: сайты, боты, AI-интеграции.

## 3. Что уже готово

- **Этап 1 — главная страница.** Премиум-дизайн, 3 языка, тёмная тема, адаптив, анимации, SEO.
- **Этап 2 — онлайн-запись** (`/booking`). Услуга → врач (или «любой») → дата → время → контакты.
  Свободное время считается из расписания врачей и существующих записей.
  Защита от двойной записи через блокировку строки врача в транзакции.
- **Этап 3 — админ-панель** (`/admin`). Вход по паролю + демо-режим только для просмотра
  (данные пациентов скрыты). Дашборд, таблица записей с фильтрами и поиском,
  смена статусов, редактор расписания, генератор демо-записей.
- **Этап 4 — уведомления в Telegram.** Код готов и опубликован: при новой записи бот пишет
  админу, в сообщении кнопки «Подтвердить» / «Отменить». Webhook защищён секретным
  заголовком. Страница `/admin/notifications` — подключение бота в пару кликов.

## 5. Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Статус | Зачем |
|---|---|---|
| `DATABASE_URL` (+ другие `DATABASE_*`) | ✅ задана | Подключение к Neon. Создана автоматически интеграцией |
| `ADMIN_PASSWORD` | ✅ задана | Пароль входа в админку. Локально пароль `admin` |
| `TELEGRAM_BOT_TOKEN` | ✅ задана | Токен бота от @BotFather |
| `SESSION_SECRET` | не задана | Необязательно: подпись сессий (иначе берётся из `ADMIN_PASSWORD`) |
| `TELEGRAM_LOCALE` | не задана | Язык сообщений бота, по умолчанию `ru` |
| `DEMO_ACCESS` | не задана | `false` скрывает демо-вход в админку |

**Важно:** после изменения переменных нужен **Redeploy**, иначе сайт их не увидит.

## 6. Как запустить локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Базу настраивать не нужно: локально поднимается встроенный
PostgreSQL (PGlite) в папке `~/.clinic-platform/pglite`, миграции и начальные данные
применяются сами. Админка: http://localhost:3000/admin, пароль `admin`.

Полезные команды: `npm run build`, `npm run typecheck`, `npm run lint`,
`npm run db:generate` (после изменения `src/db/schema.ts`).

## 7. Правила работы, о которых важно помнить

- **Пароли, токены и ключи вводит только пользователь.** Claude их не вводит в поля,
  не хранит и не пишет в код. Поэтому шаги с `ADMIN_PASSWORD`, `TELEGRAM_BOT_TOKEN`
  и вход в админку делает сам пользователь.
- **Удаление репозиториев и других данных** тоже делает пользователь сам.
- Объяснять простым языком: пользователь ещё учится, код читает, но не всё знает.
- Отвечать по-русски.
- Окно Chrome должно быть **развёрнуто на экране**: если оно свёрнуто, страница «замерзает»
  и автоматизация браузера не работает.
